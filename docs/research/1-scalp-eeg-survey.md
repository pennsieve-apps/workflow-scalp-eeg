# Scalp EEG biomarker workflow: literature and software survey (2026-11-12)

Scope: routine and long-term video-EEG scalp recordings (10-20 and high-density), epilepsy and neurology research. Candidate tools per category with paper, repo, licence, weights, runtime, GPU need, adoption. Flags: **NC** = non-commercial, **GATED** = weights behind credentialed portal / Docker-only, **AGPL**, **UNSPEC** = licence unspecified.

Notes
- Bad-channel detection: pyprep `NoisyChannels` (RANSAC, correlation, HF noise, deviation, SNR) and autoreject `Ransac` cover the standard methods; MNE itself has `mne.preprocessing.find_bad_channels_maxwell` (MEG only) and `annotate_amplitude`/`annotate_muscle_zscore` for scalp.
- Clinical long-term recordings have no EOG channels in many montages; ICLabel works without EOG (topography + spectrum + autocorrelation). It needs sensor positions (standard 10-20 montage via `make_standard_montage` is sufficient).
- MNE reads Natus/Nicolet (.e), Nihon Kohden (.EEG), EDF/EDF+, BrainVision, EEGLAB .set, Persyst .lay/.dat, and NeuroScan; `mne.export` writes EDF+ and BrainVision. This makes an `eeg-prep` app a straightforward sibling of ieeg-prep.
- Nothing in this category needs a GPU. mne-icalabel inference on a 20-30 component ICA takes seconds on CPU.

## 2. Spectral biomarkers

Verdict: the tooling is mature and permissive, but there is **no widely adopted open-source package that implements the clinical scalp-EEG biomarkers (PDR, slowing index, asymmetry) as named functions**. They are a few dozen lines on top of MNE/specparam and the published method papers below give the definitions. The app should implement them itself and cite the method papers.

| Tool / method | Role | Primary paper | Repo | Licence | Weights | GPU | Adoption |
|---|---|---|---|---|---|---|---|

Not recommended / not found
- Penn Litt lab (Bernabei 2022) spectral features are intracranial; the team already wraps them in ieeg-bandpower and can re-use the same feature code on scalp data with a 10-20 montage.
- Harvard/BDSP scalp "background" models (e.g. the hybrid background/report system, arXiv:2411.09874) and Holberg SCORE-AI (Tveit 2023, *JAMA Neurol.* 80(8):805-812) are not open; SpikeNet-family weights are gated (see section 3).
- `Travis000/seeg-aperiodic-exponent` is a thin, lesion-locked SEEG reference script, not a library.

Suggested `eeg-spectral` app outputs: per-channel specparam table (exponent, offset, peaks), band-power table (absolute, relative, log), PDR table (frequency, amplitude, asymmetry, reactivity if eyes-open/closed events exist), rBSI time course, slowing indices; BIDS derivative TSVs. All CPU.

## 3. Interictal epileptiform discharge (IED / spike) detection

Verdict: **the best-validated scalp spike detectors are not usable** (SpikeNet/SpikeNet2 weights are credentialed and CC BY-NC; Persyst is proprietary). The only open-weight, permissively-licensed scalp IED model found is small and single-dataset (SenuaLab, trained on vEpiSet). A morphology/template detector built on the team's existing epycom code is the dependable baseline; a deep model can be added as an optional step.

Datasets for training/validating an open spike detector
- **vEpiSet**: 84 patients, 20 min each (28 h), 29 channels (19 EEG + 4 auricular + ECG + EMG), 2,516 IED / 22,933 non-IED 4-s epochs, five region classes, expert consensus. figshare doi:10.6084/m9.figshare.28069568.v2, **CC BY 4.0**, 16.9 GB zip of .mat files. This is the only open, permissively licensed scalp IED corpus found.
- TUEV (TUH EEG Events) : registration/DUA only; note only.
- OpenNeuro ds003555 (section 8) has HFO markings, not spike markings.

Recommendation: `eeg-spikes` app = epycom Barkmeier (+ Janca) on 10-20 bipolar and average montages, with per-channel rates, lateralisation ratio and a sleep-stage-conditioned rate (section 6). Optional `eeg-spikes-dl` step running SenuaLab IEDNet-Lite/ResNet-Attention (CC BY 4.0 weights) with a clear "experimental" label; revisit when an open-weight model with multi-centre validation appears.

## 4. Seizure detection on scalp EEG

Verdict: SzCORE/EpilepsyBench is the right contract (BIDS-EEG + HED-SCORE TSV in, TSV events out, `timescoring` metrics). The leaderboard winner, **SeizureTransformer, has MIT code but weights only inside a Docker image** (flagged). Among the open-weight, permissively-licensed entries, nothing yet matches it; the practical choice is to ship a SzCORE-compatible app wrapper plus a classical baseline, and treat deep models as plug-ins selected by licence.

Observations
- Every challenge entry was trained on TUSZ, which is DUA-gated; that does not restrict the resulting model's licence, but it means the training cannot be reproduced inside the platform. Only EEGWaveNet (CHB-MIT) and DynaSD (CHB-MIT tuning) are trained purely on open data.
- Generalisation is poor: best F1 43% on an unseen EMU set. Any app must present outputs as review candidates with FP/day shown.
- Weights-in-Docker-only: the platform rule makes SeizureTransformer, Brain-Go-Brr, zhu_2023 and eventnet_2024 unusable as "apps with embedded weights" unless the authors publish weight files. Ask Wu et al. (MIT repo, so a file release would be unencumbered) before building anything on it.

## 5. Scalp HFO detection

- No packaged open implementation exists; it is a join: YASA hypnogram (or the alpha-delta-ratio wake/sleep proxy used by Conrad) x spike events from section 3 -> spike rate per stage per channel, NREM/wake ratio, lateralisation per stage. - Clinical long-term EEG in an EMU typically has no EOG/EMG; YASA works on a single central EEG channel (C3/C4-M1/M2 or C3-A2) with reduced accuracy; document that.

## 7. Functional connectivity / network biomarkers

Verdict: no open-source, validated scalp-EEG connectivity classifier for epilepsy diagnosis or lateralisation exists; published results (Verhoeven 2018, Coito 2019) used proprietary source-imaging pipelines and did not release code.
